# Smart Energy Analyzer

A  project that analyzes household electricity consumption, detects unusual usage patterns, predicts consumption, and provides simple energy-saving recommendations.

## Features

* Data cleaning and preprocessing
* Daily electricity consumption analysis
* Consumption pattern visualization
* Anomaly detection using IQR
* Daily consumption prediction
* Basic energy-saving recommendations

## Technologies

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Google Colab

## Dataset

**Individual Household Electric Power Consumption** dataset.

The dataset contains household electricity measurements such as active power, reactive power, voltage, current, and sub-metering values.

## Results

* Average daily consumption: **36.71 kWh**
* Maximum daily consumption: **79.56 kWh**
* Minimum daily consumption: **8.36 kWh**
* Unusual days detected: **1**
* Detected unusual day: **23 December 2006**

## Project Flow

**Data → Cleaning → Analysis → Anomaly Detection → Prediction → Recommendations**

## SDG Alignment

**SDG 7 – Affordable and Clean Energy**
